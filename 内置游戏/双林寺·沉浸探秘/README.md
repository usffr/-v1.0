# 双林寺 · 泥骨存年（像素沉浸探秘）

一个「沉浸式像素风网页游戏」：以山西平遥双林寺为背景，玩家持灯漫游古寺，
寻访各殿彩塑，集齐六片「泥骨」拓片，解开一封旧信的秘密。

> 完全离线可玩：直接双击 `index.html` 即可（无需服务器 / 无需联网）。
> 素材与代码全部原创或来自本项目自带素材，**无第三方水印**。

---

## 一、玩法

- **移动**：方向键 ↑↓←→（角色可绕到屋檐、围墙、树木之后，带景深遮挡）
- **交互**：走近金色光点 → 按 `E` 或点击 → 打开殿宇卡片（照片 + 说明）→ 收下拓片
- **目标**：集齐 6 片拓片（护 · 塑 · 相 · 愿 · 觉 · 戏），回到山门触发结局
- **彩蛋**：西南墙角的蓝色光点藏着一片无名「器」拓
- 开场有前置剧情对白（守寺老人 / 旧信），配合背景音乐《古寺星沉》

## 三、制作流程（可复现）

素材使用前先跑一遍（需要 Python 3 + Pillow + numpy）：

```bash
python tools/gen_map.py       # 生成分层地图 + 碰撞
python tools/gen_char.py      # 生成角色精灵表
python tools/build_assets.py  # 归类照片 / 迁入音频视频
node tools/selftest.js        # 可达性自检
```

### 分层与景深原则
- **地面** `ground.png` 作底图，整张铺满。
- **物件**（墙/殿宇/城门/树/石狮/石碑）各自为独立透明 PNG，带 `anchorY`（底边）。
- 运行时按 `z-index = anchorY` 做 **Y 轴深度排序**：角色 `y` 小于物件锚点 → 被遮挡（走到屋后）；
  大于 → 走在前面。因此角色能自然穿行于建筑与树木之间。
- **碰撞**：物件以 alpha 像素精确入碰撞；城墙成环，仅城门留门洞；外圈林不可通行。
  碰撞位图以 base64 内嵌 `data/map.js`，规避 `file://` 下 canvas 取像素的跨域限制。

### 照片归类
参考 `../../双林寺照片分类清单.md` 的编号，从 `../../new/` 取实际存在的照片，
按殿宇分组（山门 / 天王殿 / 千佛殿·韦陀 / 千佛殿·壁塑 / 菩萨殿·千手观音 /
罗汉殿·悬塑 / 罗汉殿·残件 / 悬塑群像 / 戏台 / 器物）。

## 四、扩展

- 新增殿宇：在 `tools/gen_map.py` 的 `halls` 列表加入（x0,y0,x1,y1），
  再在 `data/halls.js` 增加交互点；重跑 `gen_map.py` 即可。
- 新增照片：放入对应分组目录并更新 `tools/build_assets.py` 的 `GROUPS`。
- 新增剧情：编辑 `data/story.js`（对白数组，逐句点击推进）。
